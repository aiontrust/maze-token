# maze-token

The MAZE token landing page, hosted on GitHub Pages.

## Offline and install

- After one visit online, this page opens without a connection.
- Opening it while online also lets the three games (`maze-dino`, `maze-dino-daily`, `maze-tales`) save themselves, so they open offline from the Home Screen too. This works while the page and the games are on the same address (`aiontrust.github.io`).
- When you are online the newest page is always loaded; the saved copy is only used when there is no connection.
- **Install:** on iPhone use Safari → Share → Add to Home Screen. On Android use the Chrome menu → Install app.
- If a phone keeps showing an old logo or icon, change the version name in `sw.js` (`mdd-token-v1` to `mdd-token-v2`), commit, and open the page online once.
